Create a single page web application that allows users to encode and decode text using a Caesar cipher. The application should have a user-friendly interface with clear instructions and error messages.

The application should have the following features:

- A text input field for the user to enter the text they want to encode
- A text input field for the user to enter the text they want to decode.
- A dropdown menu to select the encoding method (Caesar cipher, Base64, ROT13, etc.).
- A dropdown menu to select whether to encode or decode the text.
- The user can add their message to encode or decode in the appropriate input field. The other side populates automatically.
- A text output field to display the result of the encoding or decoding.
- A copy button to copy the result to the clipboard.
- A reset button to clear the input and output fields.
- Clear instructions and error messages.
- The interface should support Themes (Light and Dark) in the same manner as is done for the markdown viewer.

The application should be styled using Tailwind CSS and should have a modern, clean, and responsive design.

Add this tool to the main Toolbox home page under the Dev Tools section.
