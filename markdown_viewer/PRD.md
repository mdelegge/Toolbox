Markdown Viewer

# Prompt:
Generate a complete HTML and JavaScript project for a Markdown viewer. The viewer should meet the following requirements:

- Single page web app.
- Text Area for Markdown Input
- Preview Area for Markdown Output
- Export Button to export the markdown as a formatted rich text file
- Copy Button to copy the markdown to the formatted clipboard
- Responsive Design
- Back button to go back to the previous page
- resizable viewer area
- Drop a markdown file to load it into the text area
- Tailwind CSS / HTML / JS
